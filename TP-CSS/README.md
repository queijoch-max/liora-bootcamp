# TP CSS — À propos de nous

**Sprint 1 · Fondamentaux**

Page « À propos de nous » réalisée en HTML et CSS.

## Contenu de la page

- Un **en-tête** avec le titre de la page.
- Une section **« Qui sommes-nous ? »** qui présente l'équipe.
- Une **galerie** de 8 images disposées en grille (images aléatoires de [Picsum](https://picsum.photos)).
- Un **footer** placé en bas de l'écran.

## Notions travaillées

- Structure sémantique HTML (`header`, `section`, `footer`)
- Mise en page avec **CSS Grid**
- Positionnement du footer en bas de page

## Fichiers

| Fichier | Rôle |
|---|---|
| `tp1-css.html` | Page complète : le HTML et le CSS (dans une balise `<style>`) dans un seul fichier, prêt à être collé dans un notebook Jupyter |

## Lancer le TP

Ouvrir `tp1-css.html` avec l'extension **Live Server** de VS Code, ou directement dans le navigateur.
