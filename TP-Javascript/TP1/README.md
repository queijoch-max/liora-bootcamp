# TP1 JS — Random User

**Sprint 1 · Fondamentaux**

Intégration d'une maquette Figma, avec une galerie d'utilisateurs générée grâce à l'API [Random User](https://randomuser.me).

## Fonctionnalités

- Un **menu** de 3 liens.
- Une **section d'accueil** avec une image de fond, un titre, un texte et un bouton.
- Une **galerie d'utilisateurs** : à chaque clic sur le bouton, 6 nouvelles fiches sont générées (photo, prénom, nom, email).
- Une section **Contact** et un **footer**.

## Notions travaillées

- Sélection d'éléments avec `getElementById`
- Écoute d'événements avec `addEventListener`
- Appel d'API avec `fetch`, `async` / `await`
- Parcours d'un tableau avec `forEach` et affichage avec `innerHTML` et les template literals

## Fichiers

| Fichier | Rôle |
|---|---|
| `index.html` | Structure de la page |
| `style.css` | Mise en forme |
| `script.js` | Appel à l'API et affichage des fiches |
| `tp1-random-user.html` | Version en un seul fichier (HTML + CSS + JS) pour Jupyter |
| `consigne.txt` | Énoncé du TP |

## Lancer le TP

Ouvrir `index.html` avec l'extension **Live Server** de VS Code.
